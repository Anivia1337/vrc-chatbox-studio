Chatbox

Mode

Build a live chatbox from elements, or page through a text file 144 characters at a time.

Arrange

Drag to reorder. Divider puts the vertical divider after an element, New line continues the chatbox on the next line.

    Add elements

    Each element is configured on the Elements page.

    Text file

    Sends the file in 144-character chunks, one per update. Everything else is paused meanwhile.

    A line with only * sends a blank frame. \n or \v inside a line makes a line break.
